# 测试工作台布局改进（v2）

承接 [prd_testing_nav_flatten.md](./prd_testing_nav_flatten.md)，针对利用率与导航观感再收敛。

## 决策

1. **模式不进面包屑**：侧栏 Switch（Agent | 测试）已表达模式；面包屑只表达 `项目 / 应用`。
2. **应用切换按项目分组**：下拉用分组标题，不是扁平 `项目/应用` 一条龙。
3. **配置内嵌**：执行环境 / 图标 / 逻辑 / 用例来源 / 设计稿全部在「测试 → 配置」内完成，不再跳 Settings。
4. **布局**：去掉重复大标题堆叠；任务态用「可伸缩主从」占满主区；未选任务时左栏加宽列表。
5. **侧栏对话记录**：去掉抢高度的 spacer，记录区 `flex:1; min-height:0; overflow:auto` 完整可滚。
